# ⚖️ Islam & Personal Status Law — الإسلام وقانون الأحوال الشخصية

**بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ**

Interactive trilingual (AR/EN/FR) educational web app based on the book **الإسلام وقانون الأحوال الشخصية (Islam and Personal Status Law)** by Sheikh Mohammed al-Ghazali (1917-1996).

## Features

- 20 cards on family jurisprudence, 5 contemporary family law issues, daily habit tracker, knowledge quiz
- Trilingual: Arabic, English, French with RTL/LTR support
- 3 unique themes with localStorage persistence
- Floating particles background, glassmorphism panels
- Swipe navigation, sound effects
- Responsive design + PWA-ready

## Tech

Pure HTML + CSS + JS. No frameworks, no dependencies. Just open `index.html`.

## Disclaimer

I am not a scholar. This is a humble effort by a Muslim parent to share Sheikh al-Ghazali's wisdom interactively. Content derived from the book and trusted Islamic sources. This is not a fatwa.
